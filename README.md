
## GitHub Actions DevOps Activity

### Workflows Implemented
- Basic workflow execution
- Push and pull request triggers
- Scheduled workflows using cron
- Manual workflows using workflow_dispatch
- External events using repository_dispatch
- Contexts and conditional execution
- Repository variables and secrets
- Multi-OS runners
- Self-hosted runner
- Matrix builds
- Dependency caching
- PostgreSQL service container
- JavaScript custom action

- GitHub Actions

- Python
- PostgreSQL
